## Weather App
A modern and responsive Weather Application built using **HTML, CSS, and JavaScript**.  
It fetches real-time weather data using the OpenWeather API.

---

### Features
- 🌤️ Search weather by city name  
- 📍 Get current location weather (Geolocation API)  
- 🌡️ Displays temperature, humidity, and condition  
- 📅 5-Day weather forecast  
- 🌙 Dark mode toggle  
- 🔍 Auto city suggestions  
- 🎨 Clean and modern UI design  

---

### Technologies Used
- HTML  
- CSS 
- JavaScript 
- OpenWeather API
